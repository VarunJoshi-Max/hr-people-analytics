

\# HR \& People Analytics



\## Project Overview

An end-to-end HR analytics project using Python, Power BI, and Git/GitHub.



\## Business Objectives

\- Analyze workforce composition and headcount.

\- Investigate employee attrition and workforce trends.

\- Explore recruitment, compensation, performance, and engagement.

\- Develop data-driven HR recommendations.



\## Tools

\- Python

\- Pandas

\- Jupyter Notebook

\- Power BI

\- Git and GitHub



\## Project Status

In progress.



\## Repository Structure

\- `data/` — Raw and processed datasets

\- `scripts/` — Python scripts

\- `notebooks/` — Exploratory analysis

\- `reports/` — Findings and documentation

\- `powerbi/` — Power BI dashboard
